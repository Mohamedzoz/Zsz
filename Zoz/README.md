# بورتفوليو م/ محمد عبد الرحيم (Zoooz) | Flagship Architecture Portfolio 🚀

موقع شخصي ومعرض أعمال تفاعلي فائق الأناقة والسرعة مخصص لعرض مشروعات وخبرات **م/ محمد عبد الرحيم (Eng. Mohamed E. Abdelrehem)** في هندسة النظم الرقمية الضخمة (Enterprise Systems Architecture)، أتمتة العمليات وروبوتات الـ RPA المستقلة، وإدارة عمليات الاتصالات وتدقيق الجداول والـ WFM.

---

## 🌟 المميزات والتصميم الحيوي (Living & Interactive UI)

- **الهوية البصرية:** Dark Obsidian Glassmorphism مع لمسات Cyber-Emerald و Electric-Cyan و Royal-Violet.
- **الخلفية التفاعلية:** Ambient Particle Web Canvas يتفاعل بانسيابية مع حركة الماوس بدقة 60fps.
- **محاكيات حية للمشروعات (Interactive Project Simulators):**
  - **Aeterna ERP:** محاكي تفاعلي لمراحل دورة الإنتاج الـ 8 + تجربة التبصيم بالرصد الجغرافي GPS Geofencing.
  - **Telecom WFM Operations:** حاسبة فترات الـ Hold والـ Closed-Open ومؤشرات الـ MTTR و SLA بالثواني.
  - **Nusuk Masar 24/7 Watcher:** شاشة تيرمينال حية لمحاكاة الرصد الآلي وإطلاق تنبيهات تليجرام التجريبية.
  - **حضانة النيل (Nile Nursery):** محاكي السجل اليومي للطفل وبوابة الوالدين وفحص كود الاستلام الأمني.
  - **محرك التقارير التنفيذي (Daily Operations):** محاكي سحب بيانات SQL وتوليد إكسيل وإرسال Outlook التلقائي.
- **تيرمينال تفاعلي (Interactive CLI):** لوحة تحكم برمجية ذكية للمطورين والتقنيين تدعم أوامر حية مثل `help`, `whoami`, `projects`, `skills`, `contact`, `sudo hire-zooz`.
- **مؤثرات صوتية مستقبلية (Web Audio Synthesizer):** أصوات نقر وتنبيهات حية مدمجة عبر كود JavaScript نقي بدون أي ملفات خارجية، مع إمكانية الكتم/التشغيل بنقرة واحدة.
- **ثنائي اللغة (Bilingual AR / EN):** دعم كامل للغتين العربية والإنجليزية مع تعديل تلقائي للاتجاهات `dir="rtl"` و `dir="ltr"`.

## 🚀 كيفية النشر على Vercel في دقيقة واحدة (Deployment to Vercel)

المشروع جاهز ومجهز بملف `vercel.json` ولا يحتاج إلى أي Build Step أو تثبيت خوادم معقدة.

### الطريقة الأولى: عبر Vercel Dashboard مع GitHub (موصى بها)
1. ارفع مجلد المشروع إلى مستودع جديد على حسابك في GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Zoz Portfolio"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/zooz-portfolio.git
   git push -u origin main
   ```
2. ادخل إلى [vercel.com](https://vercel.com) وسجل الدخول.
3. اضغط على **Add New...** ثم اختر **Project**.
4. اختر المستودع `zooz-portfolio` واضغط **Deploy**.
5. سيعطيك Vercel رابطاً مباشراً وسريعاً جداً ينتهي بـ `.vercel.app` مع شهادة SSL مجانية وتوزيع عالمي على شبكة Edge CDN!

### الطريقة الثانية: عبر أداة Vercel CLI المباشرة
1. افتح موجه الأوامر (Terminal) في مجلد `Zoz`:
   ```bash
   npx vercel
   ```
2. اتبع التعليمات السريعة في موجه الأوامر وسيتم رفع الموقع فوراً!
